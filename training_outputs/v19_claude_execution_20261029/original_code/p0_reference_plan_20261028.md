# P0 预先登记：执行 Claude 方案 9802e70

范围：新manifest中248训练文件；原始CSV逐个校验SHA256。只读，不打开验证/最终测试CSV，不改已有标签/权重。现有F/I 42ms对齐、x50Hz/F40Hz零相位滤波保持。原始时间戳只从采集头读取，不拿文件修改时间当采集时间。

1. 初始F0按已有50..min(550,onset−100)窗口。SH运动均值用评分区间内跨越相同位移的完整周期（至少2周期）；其他类用既定guard后的评分区间。运动均值不先减F0；禁止把残差-F0的代数关系当独立物理证明。
2. 分类报告原始均值对F0的一元斜率。随机三类合并的主分析控制类别、温度、绝对平均位置、平均|I|、速度RMS、平均速度；SH额外按完整周期分析，ST只作描述性佐证。每个文件等权，按condition_group（含重复运行）分组bootstrap2000次、seed20261028；报告95%区间、矩阵秩/条件数，不用样本点数伪装独立文件数。
3. 结束基准固定取原始末550..50ms；要求这500ms位移峰峰值≤0.15mm且速度RMS≤2mm/s。与初始参考比较时另要求|Δx|≤0.15mm、|ΔI|≤0.05A、|ΔT|≤0.5℃。末运动方向取该静态窗口前最后一个|v|≥5mm/s点，正方向按模型rod坐标；没有点则方向未知。报告可用数、ΔF分布及方向关系，不把不同位置/电流的末端力当作零漂。
4. 采集时间排序只画原始F0序列并报告相邻变化；测试条件顺序混杂，曲线形状不能独立确认漂移。提取头时间失败的文件标记，绝不以mtime替代。
5. 训练SH/ST低速段：相同文件按绝对x的1mm格、|I|的0.1A格和T的1℃格配对正负速度1..10mm/s；每侧至少20点，估计均值力差及中点，同时记录两侧平均速度以观察黏性混杂。仅称有限低速回线带宽，不冒充v→0的纯摩擦极限或气弹簧真值。

P1门槛（操作性判据，不是物理定律）：
- 若随机组主回归95%斜率区间完全位于[-0.25,0.25]且≥20独立条件组，可认为不支持纯常量测量漂移作为主要解释；若完全位于[0.75,1.25]则支持共同偏移解释。区间跨越/设计病态则未决。
- 只有再有独立的匹配末端证据（至少10个条件组，两方向均≥3组，方向对应力差>10N且bootstrap95%区间不跨0），以及低速两侧中点可重复/位置温度可辨识，才进入R1预载估计试验。F0落在低速带内只能佐证，不能单独放行。
- 若证据不足或混杂，不自动改变动态力目标、不按文件减均值、不启动P2。保持P0数据和证据，继续可独立开展的冻结逆解实现/验证。

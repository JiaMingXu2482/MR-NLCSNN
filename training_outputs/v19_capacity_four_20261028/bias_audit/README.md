# 四模型验证偏置审查，2026-10-28

## 结论与边界

三个被圈出的文件均存在持续均值误差，不是看图产生的错觉。两个 RLF 的主要误差分量是文件级基线；SR 同时有基线与波形误差。数据处理已按同一初始静态窗口规则扣除预载，数值实现没有发现漏减、重复减或反号。最强线索是：训练和验证文件的残差均与各文件初始力基准密切关联，而当前网络既不接收这个基准，也不接收原始安装位置。

因此，“统一扣除方法”并未解决“不同初始参考条件是否可由网络输入辨识”的问题。现有证据不足以把物理来源定为传感器漂移、真实预压或静摩擦/迟滞初态之一，也不能证明全部偏差都是数据错误。相关性中包含 F0 直接参与标签构造这一代数关系，不将相关系数作为独立的传感器故障证据。

只做冻结推理与离线诊断，未训练、未修改数据/权重/主线代码、未读取最终测试 CSV。

## 数据链路核对

1. 三个原始 CSV 的 SHA256 与清单一致；按既定原始列 F/I 42 ms 对齐及滤波重新构造力标签，与本次冻结推理读取的标签最大误差 <0.010 N（CSV 舍入/浮点精度）。
2. 实际零点窗口均为原始对齐时间 50–550 ms；力标准差约 4.10、4.15、4.31 N，位移峰峰值约 0.028、0.025、0.039 mm。新力基准分别为 -217.172、-157.547、-171.853 N。
3. 相比旧处理，本次标签改变分别为 -4.376、-3.386、+9.291 N。这些是已生效的变动，不是遗漏。
4. 后续位移仍较小时力会变化。按位移阈值识别的“运动前剩余区间”平均力相对初始窗口变化为 -4.65、+1.29、+7.83 N；该区间可能已有微小运动/静摩擦变化，不能简单当成更正确零点。该量级尤其不足以解释 RLF4 的约 +45 N 残差。
5. 处理代码 `prepare_capacity_zero_data.py:42–45` 同时扣除每文件初始力 F0，并把位置统一为初始 250 mm。`runtime/source/AA02Train/train_v19.py:102–107` 只构造运动、电流、温度输入，F0、原始安装位置不进入网络；GRU 在裁剪文件起点初始化。三个裁剪起点分别为原始对齐时间 2.386、2.184、1.566 s，初始静态区间没有进入训练序列。

## 文件级基准证据

额外冻结推理本次 34 个随机类训练文件（SR17/RLF9/RHF8）和5个随机类验证文件，四模型均做，无参数更新。

- A_MLP 训练 RLF 的 mean error 与初始 F0 的相关系数为 0.9825，斜率 0.9886；也就是说这组训练样本中 F0 每变化约 1 N，残差均值也变化约 1 N。
- 训练 RLF_RMS10mm_6Hz 的偏差为 +35.41 N，RLF_RMS15mm_4Hz 为 -20.87 N，问题同样存在于训练集，不能只归咎于验证集泛化。
- 仅使用9个训练 RLF 拟合一次线性“F0→残差均值”关系，未使用验证残差拟合。对两个验证 RLF 预测偏差分别为 -16.09、+42.85 N，实际为 -17.39、+44.51 N。对应纯诊断 RMSE 从21.90/49.56降至13.39/21.86 N。
- SR 使用其17个训练文件作同样诊断，预估偏差 -12.43 N，实际 -15.63 N，诊断 RMSE 从21.49降至15.10 N。

以上是跨文件参考条件解释力的探针，不是已批准的校正方案、正式验证指标或部署模型。类别规则/基准回归可能吸收未观测物理差异，不能直接拿来修图、修数据或用于 CarSim。

可用下式理解潜在问题：标签是 F_raw(t)−F0，而输入使用 x(t)−x0 和当前运动/电流历史。若 F0 只代表贯穿全段的传感器常偏置，扣除后应消失；若它还包含安装预压、静摩擦或历史状态，动态过程中这些分量会变化，则只扣除一个数并不保证各文件成为同一个输入输出映射。当前结果更值得优先排查后一种参考状态问题，但尚未排除测量漂移。

## 排除与未排除

- ±50 ms 搜索得到最优额外移位仅0–2 ms，RMSE改善均不足0.7%；本次均值偏差不支持继续平移时间作为主要修复。
- 在不改权重的条件下加入5 s首样本常量前缀，guard后的预测变化最大约1.1e-6 N。普通启动预热无法消除持续偏置。此实验不是重建真实台架预历史，不能排除真实初始力/迟滞状态缺失。
- 增大 GRU/MLP、加入 a/历史 dI 后，两个 RLF 的偏差基本保持。不能继续把主要原因归为网络太小；也不代表架构对全部波形误差无影响。
- 分支分解存在 c、s、b 的补偿：不同模型的 b 均值差别很大但最终偏差相近。没有 b 的独立真值，不能仅据最终均值误差断定 b 分支坏了。
- 负力加权1.5可能改变误差分配，但无法单独解释不同文件稳定地一正一负且与基准对应的偏差。

## 后续修改应针对什么

保留用户要求的“相对试验前静态预载的动态力”目标，不将整段力强行去均值。下一步应检查/显式表达初始参考条件：初始力是否是可重复物理预载还是测量偏移、安装压缩量能否可靠记录、初始静摩擦状态是否需要条件化；然后选择基准条件输入/状态初始化或预测总力后同参考差分的实现。若需要初始力输入，必须确认仿真部署时可获得同定义的量；不能直接搬入训练文件的原始传感器偏置。当前结果不足以保证某个具体改法必然有效。

## Folder Names And Condition Classes

Classify cases from the immediate parent folder of `auto_1.csv`.

- `AMP{amp}mm_{freq}Hz_{current}A` -> `1_Steady_Harmonic`
  - Example: `AMP30mm_0.83Hz_1.0A`
  - Meaning: sinusoidal displacement with amplitude `amp`, frequency `freq`, constant current command `current`.
- `RMS{rms}mm_..._{current}A` -> `2_Steady_Random`
  - Meaning: random displacement with fixed current command.
- `aRMS...` -> `3_Random_HF_Current`
  - Meaning: random displacement plus high-frequency random current excitation.
- `RMS{rms}mm_{freq}Hz[slow]` with no current suffix -> `4_Random_LF_Current`
  - Example: `RMS15mm_3Hzslow`
  - Meaning: random displacement with low-frequency random current matched to the displacement frequency class.
- Any folder containing `Vel` -> standard velocity / step-current family, exported as `5_Step_Current_Triangle` unless a more specific downstream split is explicitly requested.
  - Standard velocity example: `AMP30mm_Vel0.13`
  - Step example: `AMP50mm_Vel0.13_step5_0_1.6A_1`

Step folder naming:

- `AMP{amp}mm_Vel{vel}_step5_0_{peak_current}A[_repeat]`
- `amp`: commanded displacement amplitude in mm.
- `vel`: commanded actuator velocity setting.

- `peak_current`: commanded current peak, for example `1.6A`.
- `_repeat`: repeated run index when present.

## Raw CSV Reading

Raw files are acquisition-card CSVs, normally named `auto_1.csv`.

Read rule:

1. Open with `encoding="gbk"` and `errors="ignore"` if scanning manually.
2. Prefer scanning for `#EndHeader`; set `skiprows` to the line after it.
3. If `#EndHeader` is absent, default to `skiprows=15`.
4. Read with `pandas.read_csv(path, skiprows=skiprows, encoding="gbk")`.
5. Sampling frequency is fixed at `1000 Hz`; `dt = 0.001 s`.

Column-to-physical conversion:

```python
mts_disp = (raw.iloc[:, 3] - 4.0) / 16.0 * 1500.0
force_raw = (raw.iloc[:, 5] / 10.0) * 1000.0 * 9.80665
current_raw = raw.iloc[:, 6] / 1000.0
temp_raw = raw.iloc[:, 8]
```

Physical meanings:

- `mts_disp`: MTS displacement channel, mm.
- `force_raw`: force channel, N.
- `current_raw`: current channel, A.
- `temp_raw`: temperature channel, deg C.

## Current Sign And Step430 Notes

For new `step430` data collected on `2026-06-11`, the current direction was wired in reverse. During processing, multiply the current channel by `-1` before active-segment detection, filtering-derived `current_dot`, and output:

```python
current_raw = -current_raw
```

This sign correction is required so `current` has the same physical direction as existing `Testdata` and the trained NLCSNN input convention.

Step-current amplitude notes:

- New `2026-06-11` `step430` experiments use peak current `1.6A`.
- Older `2026-04-30` `step430` files include `1.4A` peak current cases.
- Preserve the commanded peak current from the folder name in the manifest. Do not rename or merge `1.4A` and `1.6A` cases.

Some step experiments did not finish the full current program. Do not extrapolate or pad them. Process the actual valid segment only and mark the case as `truncated-current` in quality metadata.

Known abnormal zeroing case:

- `AMP30mm_Vel0.13_step5_0_1.6A`
- This run cannot reliably find zero points with the current automatic method.
- Do not guess zero points from its corrupted/abnormal trace.
- Use fixed force and displacement zero points obtained from other normal cases under the same installation/day, and mark `zero_source=manual-zero` in the manifest.

## Filtering Policy

Recommended offline training policy:

- Butterworth low-pass in SOS form.
- Zero-phase filtering with `sosfiltfilt`.
- Filter order: `4`.
- Sampling frequency: `1000 Hz`.
- Default candidate: `force_wide`.

`force_wide` cutoffs:

- Displacement: `50 Hz`
- Force: `40 Hz`
- Current: `40 Hz`
- `current_dot`: `60 Hz`
- Temperature: `2 Hz`

Reasoning:

- Offline training and validation do not require causal real-time filtering.
- Zero-phase filtering avoids artificial lag between displacement, current, and force.
- Force and current cutoffs must preserve hysteresis shape and step edges; over-smoothing can reduce peak force and hide current transients.
- Temperature varies slowly; `2 Hz` is sufficient.
- `current_dot` is noise-sensitive but must still preserve current-edge dynamics, hence a wider `60 Hz` cutoff for the current derivative in `force_wide`.

Legacy-only policies:

- Savitzky-Golay filtering appears in older step-response validation scripts.
- Causal Butterworth filtering appears in earlier data-processing scripts.
- Treat these as historical or diagnostic references, not the default policy for new processed training datasets.

## Zeroing And Active Segment

Normal zeroing:

1. Detect the active segment on filtered signals.
2. Use the pre-active segment as baseline when possible:
   - `baseline = slice(0, active_start)` if `active_start > 10`
   - otherwise use the first `min(200, len(signal))` samples.
3. Compute:

```python
mts_ref = mean(d_f[baseline])
force_offset = mean(f_f[baseline])
rod_length = 250.0 - (d_f - mts_ref)
force = f_f - force_offset
```

Active segment detection:

- Harmonic, steady random, standard velocity, and normal step/triangle families:
  - Use displacement activity relative to baseline:
  - `abs(d_f - mean(d_f[:200])) > 0.15 mm`
- Random current + random displacement families:
  - Use filtered current threshold:
  - `current > 0.02 A`
- `step430` step-current cases:
  - Apply current sign correction first when required.
  - Use current threshold such as `current > 0.05 A`.
  - Include about `500` samples before the first active current point and `500` samples after the last active current point for response inspection unless a training export explicitly requires a tighter segment.

Manual-zero rule:

- If a file has no reliable pre-active baseline, do not invent baseline values.
- Use fixed zero points from normal same-installation cases.
- Record the zero source in the manifest:
  - `zero_source=auto-baseline`
  - `zero_source=manual-zero`
  - `zero_source=unresolved`

## Derived Channels

Always derive channels in this order:

1. Convert raw acquisition channels to physical units.
2. Correct current sign for known reversed-current files.
3. Filter displacement, force, current, and temperature.
4. Detect active segment and zero force/displacement.
5. Build `rod_length`, `force`, `current`, `temp` on the active segment.
6. Derive velocity and acceleration from `rod_length`:

```python
velocity_raw = gradient(rod_length, 0.001)
velocity = lowpass(velocity_raw, fc_disp)
accel_raw = gradient(velocity, 0.001)
accel = lowpass(accel_raw, fc_disp)
```

7. Derive current rate from corrected and filtered current:

```python
current_dot_raw = gradient(current, 0.001)
current_dot = lowpass(current_dot_raw, fc_di_dt)
```

Do not compute derivatives from unfiltered raw displacement or raw current unless doing a diagnostic comparison.

## Validation Checklist Before Processing

Before exporting a new processed dataset:

- Confirm the raw root and expected file count.
- Inventory all parent folder names.
- Classify every `auto_1.csv`; no case should remain `Unknown` unless explicitly accepted.
- Check whether the root contains new `step430` reversed-current data.
- Identify cases that require manual zeroing before conversion.
- Run a cutoff/diagnostic preview on representative cases before full export.
- Save a manifest and failures file.
- Do not mix different filter policies in the same processed output directory.

目标：训练出正向力预测准确、逆向电流求解准确、参数量和计算量适中的减振器正逆模型；重点改善 SR/RLF/RHF，兼顾周期耗散特性与后续闭环（正模型 1 kHz、逆模型 10 ms 更新，运行于 NI 设备）。

## 1. 结论摘要

1. **首要瓶颈是数据参考基准（逐文件 F0 扣除），不是网络容量。** RLF/RHF 的验证误差主要是整段不衰减的文件级常量偏置，训练集同样存在；加大 GRU/MLP 未改变偏置。
2. **次要瓶颈是验证设计。** 随机类已核验验证文件仅 SR 1、RLF 2、RHF 1，单 seed，不足以支撑架构排序。
3. 输入信息（a、历史 dI）有贡献但被混淆；状态初值不是主因；训练目标权重为中低优先级。
4. **推荐架构：** 正模型保持 A 规模（GRU 2×16、MLP 48）；逆模型用共享正模型的**精确数值求逆，并以 10 ms 保持电流为求解目标**；独立 `inv_head` 仅作对照基线，不进部署路径。
5. 先做无训练的参考基准审查（P0），再按预先写定的判据重定参考（P1，需批准），然后做多 seed 最小公平对照（P2）。

### 2.1 参考基准为首要瓶颈

**事实：**

- 随机类 34 个训练文件，偏置与 F0 相关系数 0.88–0.99，斜率 0.70–1.00（[training_associations.json](../training_outputs/v19_capacity_four_20261028/bias_audit/training_associations.json)）。
- 由 [random_file_metrics.json](../training_outputs/v19_capacity_four_20261028/bias_audit/random_file_metrics.json) 汇总（A 模型，去偏 = SSE − N·bias²）：

| A 模型 | NRMSE | 去偏后 | 文件偏置 RMS |
|---|---:|---:|---:|
| 训练 RLF（9） | 12.83% | 10.51% | 16.7 N |
| 验证 RLF（3，含未核验文件） | 17.23% | 11.62% | 27.9 N |
| 训练 RHF（8） | 8.25% | 7.00% | 14.8 N |
| 验证 RHF（1） | 12.27% | 8.04% | 26.1 N |
| 训练 SR（17） | 8.78% | 6.96% | 12.4 N |
| 验证 SR（1） | 25.77% | 18.72% | 14.7 N |

  去偏后 RLF/RHF 训练—验证差距很小：验证误差主要不是泛化问题，而是标签中有输入无法解释的常量。
- 速度分段 RMSE 在各段都约 30–48 N（[comparison.json](../training_outputs/v19_capacity_four_20261028/training_delivery/comparison.json)），与速度无关的常量偏置一致。
- `prepare_capacity_zero_data.py` 逐文件扣除 F0，并把位移统一重置到 250 mm；网络不接收 F0 与绝对安装位置。

**推断：** 三个问题文件绝对位移几乎相同（584.24 / 584.33 / 585.36 mm），F0 却为 −217.2 / −157.5 / −171.9 N，相差约 60 N（[raw_reference_audit.json](../training_outputs/v19_capacity_four_20261028/bias_audit/raw_reference_audit.json)）。如此小的位置差不能用气弹簧力差解释。

**假设（待 P0 检验）：** 偏置对 F0 斜率≈1，意味着运动段原始平均力基本不随 F0 变化。合理解释：静止时密封摩擦把力"卡"在摩擦带内某处，开始运动后该状态被抹掉；逐文件扣 F0 反而给整段标签注入常量噪声。这与偏置不衰减相符，但尚不能排除传感器零漂。

### 2.2 验证设计

- 随机类已核验验证文件：SR 1、RLF 2、RHF 1；仅 seed 7。SR 四模型 25.8–32.1% 的排序由单文件决定。
- SR 去偏后仍有 13.4–15.5 N RMSE（训练 SR 去偏约 7%），存在真实波形误差，但证据仅一个文件，暂不能定为结构问题。

## 3. 正逆模型分析

### 3.1 结构事实（`frozen_runtime/mr_nlcsnn/model_v19.py`）

- F = c·v·G_c(q) + Σ s_k·tanh(v/σ_k)·G_s(q) + b，q = 1 − 滞后有效电流；G 单调（PositiveLinear），b 与电流无关。
- 当前电流只经 `lag.step` 进入力；observer 只见历史电流。对给定上下文，力对电流严格单调，`inverse_current` 二分为精确求逆。

### 3.2 关键推断：单步求逆病态

- 训练所得 τ≈12.5 ms → 每 1 ms 步 α = 1 − e^(−1/12.5) ≈ 0.077；保持 10 ms 有效电流仅完成约 55%。
- 单步逐点求逆会把力误差放大约 13 倍为电流误差。
- 逆模型应求"未来 10 ms 内保持不变的电流 I，使窗内力与目标一致"。窗内有效电流对 I 单调，目标仍单调，二分成立。

### 3.3 逆方案比较（按代码结构估算，未在 NI 实测）

| 方案 | 额外参数 | 每 10 ms 计算量 | 精度/一致性 |
|---|---:|---:|---|
| 共享骨架逆头 `inv_head` | A 3,841；A_GRU 4,609；A_MLP 9,985 | ≈4k MAC | 近似映射，有回代误差；Stage 1 未训练 |
| 单步精确二分（32 次） | 0 | ≈40k MAC；G 查表后 <1k | 回代≈0，但受病态影响 |
| **10 ms 保持窗二分（推荐）** | 0 | 窗内冻结 c/s/b ≈0.25M MAC（≈25 MMAC/s） | 与正模型一致，符合执行器保持电流 |
| 窗内含 GRU 滚动 | 0 | ≈3.3M MAC（≈330 MMAC/s） | 需预测未来运动，cRIO 偏紧，暂不建议 |

正模型每步约 16.6k MAC（A）、≈27k（A_GRU）、≈35k（A_MLP），1 kHz 下最多约 35 MMAC/s，NI 实时 CPU 可承受；计算量不是扩网络的理由，扩网络也未带来收益。

### 3.4 推荐架构

- 正模型：A 规模（约 1.7 万可训练参数），不扩大。
- 逆模型：正模型精确数值求逆 + 10 ms 保持窗目标，G 可预先查表。
- `inv_head`：仅作对照基线。

## 4. 改进方案（按优先级）

### P0：参考基准审查（不训练，约半天 CPU，仅训练集原始记录）

预先写定判据后执行：

1. **F0 vs 运动段平均力**：SH 取整数周期、随机类取评分区间，原始力均值对 F0、T、绝对位移回归。斜率≈0 → 支持摩擦卡滞；≈1 → 支持真实零漂。
2. **结束静止段**：比较结束静态力与 F0 之差，是否随最后运动方向变号。
3. **时间顺序**：按试验先后排列 F0，判别平滑漂移还是 ±摩擦幅度跳变。
4. **摩擦带宽度**：由 ST 与 SH 低速段估计 v→0⁺/0⁻ 力差，检验约 60 N 的 F0 离散是否落在摩擦带内。

### P1：按判据重定参考（需用户批准）

仍保持"扣除试验前静态预载后的动态力"目标，只改变预载估计方式：

- **R1（摩擦卡滞成立）**：预载 = 仅依赖绝对位移与温度的气弹簧项 F_g(x_abs, T)，用训练集摩擦带中点拟合，非逐文件拟合；仿真与实车可得同定义输入。
- **R2（真实零漂成立）**：保留逐文件 F0，偏置来源另查。
- 全程不使用任何验证残差。

参考量级：仅训练拟合的诊断探针显示验证 RLF RMSE 可从 21.90/49.56 N 降至 13.39/21.86 N（[bias_audit/README](../training_outputs/v19_capacity_four_20261028/bias_audit/README.md)）。这只是改进空间的量级，不是验收目标，也不是正式修复。

### P2：最小公平对照（约 6 次 GPU 训练，4–5 小时）

- 新标签下 D、A 各 3 个 seed；数据清单、采样表、学习率调度与本次一致；只取第 300 轮最终权重，不用验证集挑 checkpoint。
- 随机类在训练文件内做分组交叉验证；现有验证集只做最终确认。
- 报告拆分为 bias、去偏 RMSE、速度分段 RMSE、换向窗误差。

### P3：仅当 P2 后去偏误差仍明显时

单变量消融，每项独立：

- 换向/低速段特征（当前 |v|<10 mm/s RMSE ≈30 N）；
- 电流动态改双时间常数（可能改善 ST/RHF）；
- 训练目标改全局固定尺度，去掉随意权重；
- 分离 a 与历史 dI 的贡献。

### P4：逆模型与闭环评估（不训练）

冻结正模型，比较 `inv_head`、单步二分、10 ms 保持窗二分；再测变化电流、非正弦激励，最后做 CarSim 接口验证。

## 5. 验收标准（提议值，需确认）

静态段力标准差约 4.1–4.3 N，可视为噪声下限参考。

| 项目 | 标准 |
|---|---|
| 正模型 | 随机类文件偏置中位数 ≤5 N、最大 ≤10 N；随机三类均值 ≤13%；SH、ST、SH6.62Hz 相对 A 退化 ≤0.3 个百分点；多 seed 均值与范围 |
| 逆模型 | 有效样本（\|v\|≥10 mm/s 且灵敏度权重 ≥0.2）电流 MAE ≤0.1 A；可达目标回代力残差 <1 N；报告饱和比例与电流总变差 |
| 时间预算 | 目标 NI 设备实测：正模型每步 ≤100 µs，逆模型每次 ≤1 ms |
| 能量 | 变化电流与随机激励下，闭合位移周期净功 ≥0；任意时间窗累计功 ≥ −E_bound（气弹簧可储能上界）；不要求瞬时 Fv ≥0；SH 验证每周期耗散能误差 ≤10% |
| 表述边界 | 有限恒流正弦扫描通过只能表述为"被测工况下周期净功为正"，不等同全域无源或闭环稳定；常量偏置闭合周期功为 B∮dx=0，偏置与净发能问题需分别验收 |

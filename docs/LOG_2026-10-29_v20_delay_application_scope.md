# 2026-10-29：v20 A/E 时延审查与应用范围更新

## 当前决策

用户说明：实际应用以**小位移、速度绝对值不超过 0.3 m/s**为主，高频工况遇到较少。

因此降低高频指标在选型中的权重，优先评价目标工作范围内的力预测和动态响应。**A 暂保留为开发候选，A/E 最终选型未锁定；没有授权本轮开始新训练或替换闭环模型。**

之前综合推荐 A 的依据是三 seed 总体/高频误差、seed7 时延和仍较小的参数规模。新的应用范围削弱了其中高频优势的决策权重，不能直接据此反推 E 更优。

注意：低速度不等于低频率。正弦运动速度幅值同时由位移幅值和频率决定。用户尚未给出“小位移”的精确上限；下一步先用现有文件名为 5/10 mm 的工况作候选子集，不能将它当作已确认的物理行程上限。

## 本轮已完成的 10%→90% 统计

定义为：

`delay = t[F0 + 0.9*(F1-F0)] - t[I0 + 0.1*(I1-I0)]`

下降阶跃也按“完成变化量”计算。数据无独立目标电流命令，以实测电流幅值的平台中位数代理目标。此指标是首个定向越阈点的间隔，不是进入并保持误差带的稳定时间，也不是一阶时间常数。

- 数据：33个ST文件，30训练、3验证；没有读取最终测试CSV。
- 电流与力均已前移42点，该共同平移不改变二者相对时延；本轮不调整数据。
- 主平台窗口：陡变开始前[-30,-10)ms、末个陡变点后[30,80)ms。
- 保留全体事件与质量标记；排除换向、明显变速、低速、平台不平等后，实测合格事件122个（上升55，下降67）。算法、阈值及剔除原因见归档README/JSON。
- 筛选后实测中位数：上升22.81ms，下降26.02ms。
- A/E使用seed7已有best权重（A epoch126，E epoch127），仅推理，权重未修改。
- 按实测合格事件配对，上升55个：实测/A/E中位数22.81/19.95/13.98ms；下降66个：25.95/23.63/21.52ms。模型自身平台质量标记仍保留，三者共同通过判据的更严格子集也已输出。

**这些合格配对事件来自训练文件。** 三个原ST验证文件中，45个可配对事件均有速度换向，不能用于隔离纯电流响应。这是筛选后适用范围的限制，不能把排除后的结果包装成独立泛化验证。该结果也不是对其他分析方法（例如速度修正）的独立验证。

## 相同速度下 ΔI 的条件趋势

为减少混杂，进一步固定50mm行程，按实测有符号速度约±120/±240mm/s分组，电流上升和下降分别统计。上升只比较I0≈0→I1，下降只比较I0→I1≈0。电流档位以0.32A阶梯分组，容差0.04A，事件表保留实际幅值。每档1–3事件，缺失档不插补。

| v约(mm/s) | 电流方向 | ΔI幅值(A) | 实测时延中位数(ms) |
|---:|---|---|---|
| +120 | 上升 | 0.64 / 0.96 / 1.28 / 1.60 | 18.35 / 19.03 / 22.16 / 22.29 |
| +120 | 下降 | 0.64 / 0.96 / 1.28 / 1.60 | 20.95 / 22.00 / 25.83 / 33.66 |
| -120 | 上升 | 1.28 / 1.60 | 30.36 / 30.33 |
| -120 | 下降 | 1.28 / 1.60 | 19.41 / 28.46 |
| +240 | 上升 | 0.64 / 0.96 / 1.28 / 1.60 | 18.55 / 20.06 / 22.33 / 22.83 |
| +240 | 下降 | 0.64 / 0.96 / 1.28 / 1.60 | 27.87 / 25.32 / 28.34 / 35.20 |

观察：部分分组随ΔI增长，部分大幅值区间趋平，不存在已证实的全局单调规律。+120mm/s下降时，三个重复文件内的9次相邻幅值比较均为正增量。下降阶跃的ΔI与起始电流同步变化，不能把初始电流影响独立出来。

A/E也未完整复现这些规律：E在多组上升阶跃下偏快，-120mm/s下降时趋势与实测相反；A在负速度上升时仍增加，而实测趋平。但样本量少且为训练文件，仅能用于诊断。

**50mm结果不能直接代表用户强调的小位移应用，即使其速度落在0.3m/s以内。**

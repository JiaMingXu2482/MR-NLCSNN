# CDC 模型接口规范（MODEL_INTERFACE_SPEC）

适用版本：`CDC_FWD_V22_E0` + `CDC_INV_V25_RI0`（均 FROZEN）
本文档与 `release_manifest.json` 的 SHA256 一同构成接口契约。

---

## 0. 总览

| | 正模型 | 逆模型 |
|---|---|---|
| 名称 | `CDC_FWD_V22_E0` | `CDC_INV_V25_RI0` |
| 作用 | 运动 + 电流 → 阻尼力 | 运动 + **目标力** → 电流增量 |
| 运行频率 | **1 kHz** | **100 Hz** |
| 输入维度 | 5 通道（原始单位） | 31 维特征（已归一化） |
| 输出 | 阻尼力 F（N） | ΔI（A），配合基准得到 I_cmd |
| 参数量 | 2073 | 2073 |

**两者不是同一个网络的两种用法**：骨干拓扑相同（GRU 2×8 + skip concat + MLP16），但
**输入特征定义、预处理、采样率、输出语义全部不同**，必须以本文档为准。

---

## 1. 正模型 CDC_FWD_V22_E0

### 1.1 输入

| # | 名称 | 单位 | 说明 |
|---|---|---|---|
| 0 | `x` | mm | 活塞位移 |
| 1 | `v` | mm/s | 活塞速度 |
| 2 | `a` | mm/s² | 活塞加速度 |
| 3 | `I` | A | 线圈电流（**模型内部会取绝对值和后移一拍**） |
| 4 | `T` | °C | 油温 |

`u (B,T,5)`，1 kHz 原始采样，**不做任何预滤波**。

### 1.2 内部归一化

```
x̃ = (x - 279.134003) / 63.970001
ṽ = v / 1000
ã = a / 50000
ĩ = clip(|I| / 1.6, 0, 1)          ← 取绝对值 + 裁剪
T̃ = (T - 40) / 40
```

### 1.3 电流历史规则（关键）

模型内部执行 `observer_input`：把电流列整体**后移一个采样点**。

```
ĩ[t] ← clip(|I[t-1]| / 1.6, 0, 1)      t ≥ 1
ĩ[0] = 0
```

即**在当前时刻 `t` 只能看到上一毫秒的电流**。这是 V22 的严格因果约定，C 移植必须保持。

### 1.4 特征

31 维，顺序与公式见 `feature_spec.json` 的 `feature_order`。要点：

- 第 3 槽是 `ĩ`（上一拍电流），第 4 槽是 `T̃`
- 其余 29 槽是运动量与 `ĩ`/`T̃` 的交叉项
- **不存在可自由调整的顺序**，顺序错位会直接导致输出错误

### 1.5 输出

```
F_normalised = model(u)               # (B,T)，约 -1..1
F_N          = F_normalised * 7664.259766
```

- 单位：**N**
- 符号：与实测阻尼力同号（压缩/伸张沿用传感器约定，未做翻转）
- 无裁剪、无后处理

### 1.6 状态与更新顺序

```
上电 / 换记录：h ← 0（两层 GRU 隐状态都清零）
每 1 ms：
    1. 用 t-1 的电流构造 ĩ[t]
    2. 构造 31 维特征
    3. h, F = gru_step(features, h)
    4. 输出 F
```

- **无固定滑动窗口**，整条序列递推。
- 文件/记录之间**不得串接状态**。

### 1.7 调用方式（PyTorch 参考）

```python
import torch, sys
sys.path.insert(0, "Forward_Model/CDC_FWD_V22_E0")
from model_def import V22Model

net = V22Model("E0")
net.load_state_dict(torch.load("Forward_Model/CDC_FWD_V22_E0/best.pth",
                               map_location="cpu", weights_only=True)["state_dict"])
net.eval()
with torch.no_grad():
    F_N = net(u) * 7664.259766        # u: (1,T,5) float32
```

## 2. 逆模型 CDC_INV_V25_RI0

### 2.1 输入

31 维，**已归一化**，100 Hz：

| 槽位 | 名称 | 单位 | 来源 |
|---|---|---|---|
| 0–19 | motion 特征 | — | 见 2.4 |
| 20 | `F_des` | — | `F_meas_filtered[k] / 7664.259766`（目标阻尼力，N） |
| 21 | `I_past` | — | `I_meas_filtered[k-1] / 1.6`（**有符号、未裁剪**） |
| 22–30 | `F_des` × 运动交叉项 | — | 见 2.4 |

### 2.2 预处理（必须逐位复现）

```
1) 61 抽头因果窗函数 sinc 低通，截止 40 Hz，Hamming 窗
    y[n] = Σ_{i=0..60} h[i] · x[n-i]        （零初始状态）
2) 每 10 点抽取，从索引 0 对齐
3) 对 x, v, a, I, T, F 六个通道全部执行
```

- 系数见 `fir_61tap_40hz.json`（61 个 double，DC 增益 1.000000）
- **群时延 30 ms**，所有通道相同
- 抽取后归一化：`x̃=(x−x_ref)/x_scale`，`ṽ=v/1000`，`ã=a/50000`，`T̃=(T−40)/40`

### 2.3 残差基准（**本模型的定义核心**）

```
I_base[k] = clip(|I_meas_100Hz[k-1]|, 0, 1.6)      [A]
```

- 必须是**实测**电流，**不是**上一拍命令，**不是**上一拍预测值
- 必须来自**同一文件/同一段记录**，不得跨记录沿用
- 文件第一个控制拍没有同文件上一拍电流 → 训练与评估均排除；上电首拍建议基准置 0

### 2.4 ⚠ 两个“上一拍电流”不是同一个量

| 用途 | 表达式 | 取绝对值 | 裁剪 |
|---|---|---|---|
| **残差基准** `I_base` | `clip(\|I[k-1]\|, 0, 1.6)` A | 是 | 是 |
| **特征槽 21** `I_past` | `I[k-1] / 1.6` | **否** | **否** |

同一传感器采样点、**两种不同变换**。C 移植时**不得合并**，也不得把基准写进特征槽。

### 2.5 输出与合成

```
ΔI      = model(x)                       # (B,T)，A，无界、可负
I_raw   = I_base + ΔI
I_cmd   = clamp(I_raw, 0.0, 1.6)         # 部署输出
```

- **训练损失用未裁剪的 `I_raw`**，裁剪只发生在部署侧
- 实测：raw 越界率 **8.05%**，clip 触发率 **8.05%**（全部来自下界）

### 2.6 motion 特征（槽 0–19）

| 槽 | 名称 |
|---|---|
| 0 | x |
| 1 | v |
| 2 | a |
| 3 | v（第二份，保留原始顺序） |
| 4 | x·v |
| 5 | tanh(2·v₊) |
| 6 | tanh(v₊/0.1) |
| 7 | v₋·\|v\| |
| 8 | v₋³ |
| 9 | a·v₋ |
| 10 | tanh(v/0.1) |
| 11 | x² |
| 12 | x³ |
| 13 | \|a\| |
| 14 | a·v |
| 15 | \|a\|·tanh(v/0.1) |
| 16 | exp(−\|v\|/0.1) |
| 17 | x·exp(−\|v\|/0.1) |
| 18 | \|x\|·exp(−\|v\|/0.1) |
| 19 | tanh(v/0.1)·\|x\| |

其中 `v₊ = max(v,0)`，`v₋ = −min(v,0)`。

condition 11 槽：`F_des`、`I_past`、`v·F_des`、`v·I_past`、`F_des·tanh(v₊/0.1)`、
`F_des·v₋·\|v\|`、`F_des·tanh(v/0.1)`、`a·F_des`、`F_des·\|a\|`、
`F_des·x·exp(−\|v\|/0.1)`、`F_des·\|x\|·exp(−\|v\|/0.1)`。

### 2.7 状态与更新顺序

```
上电 / 换记录：h ← 0；I_base 无定义（首拍由上层决定，建议置 0）
每 10 ms（第 k 拍）：
    1. 读本拍 1 kHz 缓冲（最近 10 点），推进 FIR 状态，抽取得到 k 拍样本
    2. 归一化，由 k-1 拍实测电流得到 I_past（特征槽 21）
    3. 构造 31 维特征
    4. h, ΔI = gru_step(features, h)
    5. I_base = clip(|I_meas[k-1]|, 0, 1.6)
    6. I_cmd = clamp(I_base + ΔI, 0, 1.6)
    7. 下发 I_cmd，等待下一拍实测电流回读
```

### 2.8 调用方式（PyTorch 参考）

```python
import torch, sys
sys.path.insert(0, "Inverse_Model/CDC_INV_V25_RI0")
from model_def import ResidualI0

net = ResidualI0()
net.load_state_dict(torch.load("Inverse_Model/CDC_INV_V25_RI0/best.pth",
                               map_location="cpu", weights_only=True)["state_dict"])
net.eval()

h = net.init_state(device="cpu")
with torch.no_grad():
    delta, h = net.step(features_31, h)        # 单拍
I_cmd = (I_base + float(delta)).clamp(0, 1.6)
```

## 3. 正逆模型接口一致性核对（逐项）

| 项 | 正模型 | 逆模型 | 是否一致 / 说明 |
|---|---|---|---|
| 位移 x | mm，原始 1 kHz | mm，**FIR 40 Hz 滤波 + 抽取** | ❌ **预处理不同**，见 §4.1 |
| 速度 v | mm/s，原始 | mm/s，滤波后 | ❌ 同上 |
| 加速度 a | mm/s²，原始 | mm/s²，滤波后 | ❌ 同上 |
| 电流 I | `clip(\|I\|/1.6,0,1)`，**取绝对值并裁剪**，1 拍延迟 | `I_past = I/1.6` **有符号不裁剪**；基准 `clip(\|I\|,0,1.6)` | ❌ **变换不同**，见 §4.2 |
| 温度 T | (T−40)/40 | 仅通过 `v·T` 之类不进逆模型；逆模型无 T 槽 | ⚠ 逆模型不含温度 |
| 力 F | 输出 N | 输入 `F_des = F/f_scale` | ✅ **缩放一致**（同一 `f_scale = 7664.259766`） |
| 归一化参数 | 8 个 | 同样 8 个（同一组数值） | ✅ 一致 |
| 时间索引 | 1 kHz，电流 `I[t-1]` | 100 Hz，电流 `I[k-1]` | ⚠ **单位不同**：t 是 1 ms，k 是 10 ms |
| 采样率 | 1 kHz | 100 Hz | ⚠ 级联需 10× 零阶保持 |
| 参数量 | 2073 | 2073 | ✅ 相同 |

### 3.1 结论

**接口不是天然一致。** 只有「力的缩放」和「归一化常数」可直接共用；运动的预处理、电流的
变换、时间索引三者**都不同**。级联时必须显式处理，不能把两边的同名变量当成同一个量。

## 4. 级联时的已知不一致（不在本次冻结范围内修改）

### 4.1 运动信号的滤波差异（影响最大）

逆模型的 `x/v/a` 经过 **61 抽头 FIR（40 Hz）+ 10 点抽取**，群时延 **30 ms**；
正模型使用**未经滤波的 1 kHz 原始值**。

后果：若在 HIL 中让逆模型决定电流、正模型预测力，两者看到的运动状态**相差约 30 ms**。
这会让 `forward_model_loop_force_error` 类指标混入纯相位误差。

**本次冻结不修改任何一侧**（修改将违反"不改输入特征定义"）。如后续需要闭环，
必须单独立项决定是给正模型也加同样的滤波器、还是给逆模型加延迟补偿。

### 4.2 电流符号与裁剪

- 正模型只用电流**幅值**，`clip(|I|/1.6,0,1)`，且延迟 1 ms；
- 逆模型特征用**有符号** `I/1.6`（不裁剪），残差基准用 `clip(|I|,0,1.6)`。

因此逆模型需要**双极性电流传感器**；若硬件只能测幅值，特征槽 21 会系统性偏高。

### 4.3 采样率

逆模型 100 Hz 输出，正模型 1 kHz 输入。级联时逆模型输出需**零阶保持 10 个 1 ms 步**。
注意 V24 已验证：100 Hz ZOH 喂正模型不会显著恶化（10.229% vs 10.595%，反而略好）。

## 5. C 移植验收方法

每个模型目录内提供 `golden_vectors.npz`：

| 模型 | 内容 |
|---|---|
| 正模型 | 200 个 1 ms 样本的 5 通道原始输入 + 期望输出（N） |
| 逆模型 | 100 个控制拍的 31 维特征 + 残差基准 + 期望 ΔI + 期望 I_cmd |

**验收标准**：C 实现在同样输入下的输出与期望值相对误差 < 1e-4（float32 量级），
逐点比对通过后才允许进入 HIL。

## 6. 版本保护

- 发布目录所有模型文件已设为**只读**。
- `release_manifest.json` 记录每个文件的 SHA256；任何改动都会使校验失败并作废该版本。
- 后续实验**不得**写入 `D:\CDC_Model_Release\`；新实验一律使用新目录与新版本号。
